# business-cases

Репозиторий с продуктовыми аналитическими кейсами. Каждый кейс оформлен в виде Jupyter-ноутбука и включает полный цикл работы с данными: загрузку и очистку, EDA, расчет метрик, построение визуализаций и формулировку выводов.

## Содержание

### Taxi Aggregator Conversions

Анализ воронки заказа в агрегаторе такси. Рассчитаны конверсии по этапам: создание заказа -> назначение водителя -> прибытие -> завершение поездки. Проведено сравнение пиковых и непиковых часов, выявлены города с наибольшими отклонениями конверсии, локализована проблема фрод-действий водителей с фейковыми координатами прибытия. Отдельно проанализирован тариф "Доставка" с декомпозицией воронки по городам.

**Инструменты:** pandas, plotly

### Bank Reserves Calculation

Расчет объема резервов банка по просроченным кредитам на отчетную дату с учетом типа кредита и дней просрочки. Реализована функция для автоматического пересчета резервов на произвольную дату. Смоделирован сценарий отсутствия платежей с прогнозом роста резервов и оценкой абсолютного и процентного прироста. Построены визуализации распределения резервов по типам кредитов.

**Инструменты:** pandas, matplotlib

### Webinar Analysis

Анализ эффективности каналов привлечения на продающий вебинар. Рассчитана конверсия от регистрации до посещения по площадкам. Внутри каждой площадки проведен разбор подканалов. Построена динамика числа зрителей онлайн с привязкой к расписанию вебинара, выявлен сегмент контента с наибольшим оттоком аудитории.

**Инструменты:** pandas, matplotlib

### Internship Case: использование сервисов Города

Исследование поведения клиентов экосистемы в сервисах "Город". Проанализирован сервис "Афиша": распределение заказов и среднего чека, динамика по месяцам, сегментация пользователей по частоте покупок. Оценен оборот сервиса, сформулированы рекомендации по целевым сегментам.

**Инструменты:** pandas, matplotlib, seaborn
